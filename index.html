Jednokratno povezivanje s GitHubom

Da bi stranica sama spremala artikle, treba joj GitHub token. Token ostaje samo u pregledniku ovog uređaja i nije dio koda stranice.

Kako ga napraviti (jednom): na GitHubu otvori Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Odaberi samo repozitorij ove trgovine, a u dozvolama za Contents postavi Read and write. Kopiraj token i zalijepi ga ovdje. Nazivi izbornika na GitHubu se ponekad mijenjaju.
